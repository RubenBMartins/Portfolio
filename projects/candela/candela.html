Description

This project consists of retrofitting a production line by Astriane, the Candela production line!
Programming, 3D modeling, workshop interventions, this project has it all.
This production line is divided in two machines, both of which I've worked on to some extent, as it was a class project.

Candela 1

This machine takes paraffin, optional colored dyes, and compresses it into a candle shape.

Candela 2

This machine takes the solidified paraffin, inserts the wick, the aluminum cover, and delivers it inside boxes thanks to an unstacker.

The project

Workshop

Disassembling, reassembling, getting measures, and placing new pieces, required physical work at the workshop. This aspect was crutial to getting the proper data for 3D modeling mock-ups of each machine from the production line.

3D modeling

I was put in charge of the 3D model of Candela 2, being very experiences with Solidworks. I was able to assemble the machine digitally, handle its constraints, and animate it to showcase how it works. Taking measures in the workshop was crutial to ensure the machine was accurate, with a certain leeway of precision.

Programming

I was tasked to handle the programming of the Programmable Logic Controller (PLC), so it could communicate with the Human-Machine Interface (HMI), and ensure that HMI input would actually update the state of the machine, so that it could be operated without needing to manually turn on switches in the electrical panel.
